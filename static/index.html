Privacy boundary

  • This compatibility web app transiently sends a selected standard PDF to Render for bounded text extraction.
  • Raw PDF bytes never go to Groq and are not retained as report history.
  • Extracted or pasted resume text and an optional job description go to Groq only after consent.
  • The service and this browser keep no content or report history.
  • Generated feedback can quote, transform, or restate submitted personal or job content; review it before copying or sharing.
  • An opaque installation security identifier and rate-limit state protect the service without ads or tracking.
  • App-controlled metrics are content-free. Render may separately process connection, HTTP, and Device/IP metadata under its policy.
  • Groq retains usage metadata and may retain inference content for up to 30 days unless Zero Data Retention is enabled; the production setting is unverified.
