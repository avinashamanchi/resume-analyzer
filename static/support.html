Support and limits

Useful feedback has limits.

iPhone document help

The signed iOS app extracts PDF text on-device with Apple PDFKit or Vision and asks you to review it before consent. Use a readable, unencrypted PDF under 10 MB. If recognition is incomplete, correct the reviewed text or paste up to 30,000 characters. The optional role description accepts up to 20,000 characters.

Compatibility web help

The compatibility web app transiently uploads a selected standard PDF to Render for bounded extraction. Raw PDF bytes never go to Groq. This browser does not save report history.

Local workspace

Local reports, local resume versions, and job notes do not sync to Resume.AI servers. Use in-app deletion for individual records or Delete All for the active workspace. Restoring a device backup can restore older local data.

Subscriptions

Use Restore Purchases if a valid Apple subscription is not reflected. Manage or cancel it in Apple subscription settings. For an App Store charge or refund request, use Apple purchase support; Apple decides refund eligibility under its policies. Deleting the app does not cancel a subscription. RevenueCat verifies the entitlement but does not receive full payment-card details from Resume.AI.

Troubleshooting

  • Confirm the app version, iOS version, and stable error category displayed.
  • Retry manually on a trusted network; the app does not silently repeat an AI request.
  • If deterministic feedback appears without AI, capacity or the provider may be temporarily unavailable; the deterministic result remains usable.
  • If purchase state is stale, use Restore Purchases and reopen the plan screen.

This first-party support page is the release-candidate self-help surface. For content-free bug reports, use the public project issue tracker.

Never send or publish a resume, job description, token, request identifier, filename, contact detail, or other private data when asking for help. Never post resume or job-description content. Include only the app version, operating-system version, action taken, and stable error category.

Product limit

Resume.AI is coaching, not an exact ATS, hiring decision, employment prediction, or professional advice. AI can be incomplete or wrong.
