Support and limits

Useful feedback has limits.

What the readiness review does

It combines deterministic checks for structure, impact, readability, and relevant terms with AI coaching from Groq. A readiness score helps prioritize edits; it is not a prediction or guarantee of an outcome.

File help

Use a readable, unencrypted PDF under 10 MB, or paste up to 30,000 characters of resume text. If a PDF is image-only, paste its text instead. The role description is optional and accepts up to 20,000 characters.

Request help

There is no automatic retry. If a request times out or the service is unavailable, wait and submit again manually. If you repeatedly see a service configuration message, contact the site operator with the request ID shown by the service, if one is available.

Accessibility

The form supports keyboard navigation, browser zoom, visible focus, and reduced-motion preferences. Use a modern browser that supports request cancellation and secure random request identifiers.
